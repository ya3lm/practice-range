# Practice Range — instructions for Claude Code

A first-person reflex trainer (Aimlabs-style) whose targets learn to dodge via reinforcement
learning. Portfolio project. Browser (WebGL/WebGPU) first. Read PLAN.md for the full plan and
content/content-safety.md before touching anything that appears on screen.

## Layout
- `unity/` Unity 6 project (target editor 6000.6.7f1). All code under `Assets/_Project/`.
- `ml/` Python ML-Agents trainer configs and plotting.
- `tools/` shell scripts; every editor action must be runnable from here without the GUI.
- `content/` post drafts, shot lists, safety spec. Never shipped.
- `web/` notes for hosting. The actual WebGL template is `unity/Assets/WebGLTemplates/PracticeRange/`.

## Toolchain
- Unity CLI: `~/.unity/bin/unity` (official Unity CLI). Editor binary:
  `/Applications/Unity/Hub/Editor/<version>/Unity.app/Contents/MacOS/Unity`.
- Pick the editor version from `unity/ProjectSettings/ProjectVersion.txt` (currently 6000.6.7f1).
  `tools/bootstrap.sh` is idempotent and regenerates scenes, prefabs, mode assets, URP assets, build settings.
- Python: `uv` is installed. `cd ml && uv venv && uv pip install -r requirements.txt`.
- Node 22 is available for the WebGL template and jslib tooling.

## Commands (always via tools/, never ad hoc)
| Task | Command |
|---|---|
| First-time project setup, create scenes/prefabs/assets | `tools/bootstrap.sh` |
| EditMode + PlayMode tests | `tools/run_tests.sh [EditMode|PlayMode]` |
| WebGL build to `build/webgl` | `tools/build_webgl.sh` |
| Train a dodge policy | `tools/train.sh close|mid|far [run-id]` |
| Plot a training run for a post | `uv run ml/scripts/plot_training.py ml/results/<run-id>` |
| Deploy to itch.io | `tools/deploy_itch.sh` (needs butler + ITCH_USER/ITCH_GAME) |
| Deploy to GitHub Pages | `tools/deploy_pages.sh` |

Logs: Unity batch runs write to `build/logs/*.log`. Test results are `build/test-results-*.xml`.
Read those before re-running anything.

## Conventions
- One MonoBehaviour per file, namespace `PracticeRange.<Folder>`.
- Tunables live in ScriptableObjects (`Modes/`) or `SettingsData`, never as literals in behaviours.
- Pure logic (sensitivity math, reward shaping, bandit updates, convex hull) is plain C# with no
  UnityEngine dependency beyond `Vector3`/`Mathf`, so it is testable in EditMode.
- Everything the bootstrap creates must be recreatable: `ProjectBootstrap.Run()` is idempotent.
- No asset-store assets. Primitives, procedural meshes, synthesized audio only.
- Input System only (no legacy `Input.` calls).
- WebGL: no threads, no `System.IO` file dialogs; file upload goes through `FileBridge.jslib`.
- Do not commit `unity/Library`, `build/`, or `ml/results/*` except the CSV/PNG charts referenced by a post.

## Content rules that affect code
- Target style defaults to Cube/Sphere. Mannequin is opt-in via settings.
- Imported meshes: reject skinned meshes, cap 50k tris / 10 MB, convex hull ≤255 tris.
- No gun mesh. Weapon skins: `Tracer` (default) and `Nerf` (foam dart projectile).
- SFX are generated by `ProceduralSfx`; never add recorded gunshot audio.

## Hard-won gotchas (verified 2026-10-26 on 6000.6.7f1)
- **`EditorSceneManager.NewScene` unloads assets held only by managed references.** Any asset loaded *before*
  NewScene serializes as `{fileID: 0}` in the saved scene. `ProjectBootstrap` therefore re-loads every asset
  inside each Build*Scene method, after NewScene. Keep it that way.
- **`GameObject.CreatePrimitive` is not safe in a stripped WebGL player.** Use `Primitives.Create`, which uses
  built-in meshes serialized on GameLoop/TrainingArenaConfigurator.
- **`Shader.Find` and `new Material(shader)` are not safe in the player.** Use `Shaders.NewUnlit(color)`, which
  copies the serialized `Base.mat`. Never add a `Shader.Find` outside `Shaders.cs`/Editor code.
- **A fresh ProjectSettings makes Unity inject its default package set** (App UI, Purchasing, Analytics, …).
  `Packages/manifest.json` is trimmed on purpose; `com.unity.dt.app-ui` stays because Sentis depends on it.
- **Development WebGL builds fail to link on this editor** (il2cpp embind symbols). `tools/build_webgl.sh --dev`
  keeps full exception stack traces on the release link path instead of `BuildOptions.Development`.
- **`Reset()` is a Unity message**; never name a MonoBehaviour method `Reset`.
- **The browser-pane console persists across page loads.** When verifying a new build, read the *latest* messages,
  not `onlyErrors`, or you will chase errors from a previous build.
- `Object.GetInstanceID()` is a compile error on 6.6; use `GetEntityId()`.
